## 正文

谁懂啊，夜里 vibe coding 正上头
突然弹一句 hit usage limit
任务断在那，额度要5小时后才恢复
人总不能坐着干等到凌晨4点吧？

之前的解法居然是：开另一个 AI agent
用 computer use 盯着屏幕，定时点"继续"
……烧钱烧 token，还贼不稳定

我直接写了个 100 行的 shell 守护进程：
429-wait

撞墙自动唤醒：日志里一旦出现 usage limit / 403 / 429，后台自动拉起
每30分钟发一个最小探测请求，确认额度是否恢复（几乎零成本）
额度一恢复，自动执行 resume 命令让 agent 接着跑任务，然后自己退出

不开浏览器、不用 computer use、不烧多余 token
PowerShell + bash 双版本，Windows / Mac / Linux / 手机 Termux 都能跑

已开源，MIT 协议，拿去用
